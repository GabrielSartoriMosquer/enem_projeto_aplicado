# Dataset demonstrativo

`enem_demo.csv` é um conjunto **sintético e determinístico**, criado somente para permitir que a aplicação seja executada e testada sem baixar os microdados oficiais do INEP.

Ele contém as mesmas colunas usadas pelo contrato de dados do projeto, edições de 2018 a 2025 e relações artificiais suficientes para demonstrar os gráficos.

**Não use os valores do modo demonstração em conclusões acadêmicas.** Para análises reais, execute o ETL oficial.
